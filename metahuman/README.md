# MetaHuman с мимикой с вебки: гайд под RTX 4060 Laptop (8 ГБ)

Фотореалистичный цифровой человек из Unreal Engine повторяет твою мимику и повороты головы по обычной вебке.
Дальше картинка идёт через OBS в Discord, так же как с Deep-Live-Cam.

Цепочка: **вебка → Live Link, источник MetaHuman (Video) → персонаж MetaHuman в Unreal → OBS → Discord**.

Названия кнопок взяты из документации Epic для версии 5.6. В более новых версиях они могут немного отличаться.

---

## 0. Место на диске

Это главное препятствие. Unreal Engine после установки весит намного больше, чем скачивается.

| Что | Примерно |
|---|---|
| Epic Games Launcher | ~1 ГБ |
| Unreal Engine 5.6+ без лишних платформ | 50–70 ГБ |
| Проект с одним MetaHuman | 10–20 ГБ |
| Запас под кэш шейдеров и временные файлы | 10–20 ГБ |
| **Итого** | **~80–110 ГБ** |

Сейчас на диске C у тебя свободно около 26 ГБ. Нужно освободить ещё **минимум 80 ГБ** или поставить
движок и проект на внешний SSD, подключённый по USB 3.

Найти, что занимает место, поможет скрипт [`disk_report.ps1`](disk_report.ps1):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\AI\claude\metahuman\disk_report.ps1
```

Он ничего не удаляет, только показывает самые большие папки и что обычно можно безопасно почистить.

## 1. Установка Unreal Engine

1. Скачай **Epic Games Launcher**: https://store.epicgames.com/download
   Нужен аккаунт Epic Games, он бесплатный.
2. В лаунчере: **Unreal Engine → Library → значок + рядом с Engine Versions**. Выбери самую свежую версию, но не ниже 5.6.
3. Перед установкой нажми **Options** и сними всё лишнее, это сэкономит десятки гигабайт:
   - сними **Target Platforms**: Android, iOS, Linux, TVOS и прочие. Оставь только Windows;
   - сними **Starter Content**, **Templates and Feature Packs**, **Engine Source**, **Editor symbols for debugging**.
4. Путь установки можно поменять на внешний диск.
5. Жди, это долго: десятки гигабайт плюс распаковка.

## 2. Проект и плагины

1. Запусти движок → **Новый проект → Games → Blank**, Blueprint, Desktop, качество **Maximum**
   (на Scalable отключается реалистичный свет Lumen, кожа выглядит плоской).
2. **Правка → Плагины**, поиск `MetaHuman`. Включи **MetaHuman Creator** и **MetaHuman Animator**,
   плюс **MetaHuman Live Link**. Core Tech подтянется сам. Перезапусти редактор.
3. **Основные данные MetaHuman Creator** ставятся отдельно, вместе с движком:
   лаунчер → Unreal Engine → Библиотека → стрелка у версии движка → **Параметры** →
   галочка **«Основные данные MetaHuman Creator»** (~6 ГБ) → Применить. Без них в конструкторе красная надпись.
4. Если `.uproject` не открывается двойным кликом, сделай ярлык прямо на `UnrealEditor.exe` с путём к проекту.

### Лёгкая сцена вместо открытого мира

Шаблон Blank в 5.8 открывает огромный ландшафт, он съедает несколько ГБ памяти, и MetaHuman потом не собирается.
**Файл → Новый уровень → «Базовые»**, сохранить как `Room`.
**Правка → Параметры проекта → Карты и режимы → Карта запуска редактора: Room.**

## 3. Персонаж

Два пути:
- **Свой:** Панель ресурсов → правый клик → **MetaHuman → Персонаж MetaHuman** → Заготовки → подкрутить →
  «Создать полный каркас» (облако Epic).
- **Готовый с Fab:** раздел MetaHuman на fab.com, качать файл `.mhpkg` с отметкой твоей версии UE,
  перетащить в Панель ресурсов. У таких персонажей каркас уже есть.

## 4. Сборка и память

Конструктор → **Сборка**: Assembly **UE Optimized**, Quality **High** или **Medium**, кнопка **«Собрать»**.

Открыть и собрать MetaHuman хочет **10 ГБ свободной оперативки**. На ноуте с 32 ГБ:
- закрой браузер, Telegram, лаунчер Epic (из трея: правый клик → Закрыть);
- перезапусти Unreal перед сборкой, чтобы в памяти не висели другие персонажи;
- если окно всё равно ругается, а сохранено всё, жми «Да», Windows доберёт из файла подкачки.

После сборки внизу «Не сохранено: N» → **Ctrl+Shift+S**. Появится `MetaHumans/<имя>/BP_<имя>`.
Перетащи его в сцену.

## 5. Вебка

1. **Окно → Виртуальное производство → Live Link → + Добавить → MetaHuman (видео)**.
2. Capture Device, камера, формат с наибольшим fps и при нём наибольшее разрешение, **Подключить**.
   Если не задать имя субъекта, он назовётся по камере, это нормально.
3. Нажми на субъект, смотри в камеру спокойно → **«Захватить нейтральные»**.
4. В жёлтом предупреждении про **«Экономить ресурсы ЦП в фоновом режиме»** нажми **Отключить**,
   иначе картинка замирает, когда активен Discord или OBS.
5. Выдели персонажа → Сведения → раздел **Live Link**: **Live Link Subject** = твой субъект,
   галочка **Use Live Link**. **Use ARKit** не включать, это для айфона.
6. Чтобы не подключать каждый раз: Live Link → **Готовые настройки → Сохранить как готовую настройку**,
   потом **Параметры проекта → Live Link → Default Live Link Preset**.

## 6. Вывод в Discord

1. Поставь камеру сцены так, чтобы персонаж был в кадре по плечи. Удобно добавить **Cine Camera Actor**
   и смотреть через него: правый клик по камере → **Pilot**.
2. Чтобы окно было без интерфейса редактора: **Play → New Editor Window (PIE)**, и в нём **F11** для полного экрана.
3. В OBS: источник **Захват окна** → окно Unreal → **Запустить виртуальную камеру**.
4. В Discord выбери камеру **OBS Virtual Camera**, как в гайде по Deep-Live-Cam.

### Звук с задержкой

Картинка с персонажем отстаёт от голоса на долю секунды. Чтобы губы попадали в слова,
голос можно задержать: **VB-Cable** даёт виртуальный микрофон, а программа **audiorepeater** гонит в него звук
с твоего микрофона с задержкой. В Discord тогда выбираешь микрофоном CABLE Output.

- VB-Cable: https://github.com/iperov/DeepFaceLive/releases/download/VBCABLE/VBCABLE_Driver_Pack43.zip
- audiorepeater: https://github.com/iperov/DeepFaceLive/releases/download/AUDIOREPEATER/audiorepeater.exe

В audiorepeater: **Wave in** твой микрофон, **Wave out** CABLE Input. Задержку подбирай на глаз.

## 7. Если тормозит

Трекинг по видео сам по себе сильно грузит видеокарту, Epic отдельно об этом предупреждает.

- **Settings → Engine Scalability Settings → Medium** или **Low**. Для созвона разница почти незаметна.
- Не держи окно редактора на весь экран, когда работает окно Play.
- Персонаж должен быть собран через **UE Optimized**, а не UE Cine.
- Ноут на зарядке, режим максимальной производительности.
- Закрой браузер и всё лишнее.

## 8. Если что-то не работает

| Симптом | Что делать |
|---|---|
| Нет **MetaHuman (Video)** в списке источников | Не включён плагин MetaHuman Live Link или версия движка ниже 5.6. |
| Камера не открывается после Connect | Камеру держит другая программа. Закрой всё, переподключи источник. |
| Камеры нет в списке форматов | Отключи **Filter Format List**: он прячет форматы ниже 500x500 и ниже 24 fps. |
| Трекинг есть, персонаж не двигается | Проверь **Use Live Link** и **Live Link Subject** в Details, нажми **Play**. |
| Голова двигается, лицо нет, или наоборот | Посмотри настройки субъекта: там отдельно включаются лицо и поворот головы. |
| Шейдеры компилируются вечность | Это нормально при первом запуске, может занять час. Потом быстрее. |
