# Deep-Live-Cam на созвоне: гайд под RTX 4060 Laptop (8 ГБ)

Подмена лица в реальном времени с вебки в Discord, Zoom, Telegram.
Цепочка: **Deep-Live-Cam → OBS Virtual Camera → мессенджер**.

Железо, под которое писался гайд: i7-13620H, 32 ГБ RAM, RTX 4060 Laptop 8 ГБ, Windows 10/11.
Этого хватает на 20–30 fps в 720p с включённым улучшайзером лица.

---

## 0. Освободи место на диске

На твоём ноуте занято 917 из 962 ГБ. Установка съест примерно:

| Что | Размер |
|---|---|
| venv с torch cu128, CUDA/cuDNN pip-пакетами и зависимостями | ~7–8 ГБ |
| Модели | ~0.5 ГБ |
| OBS Studio | ~0.3 ГБ |

Нужно **минимум 12 ГБ свободных**, лучше 20. Скрипт установки откажется запускаться, если меньше 12.
Быстро почистить: `Параметры → Система → Память → Временные файлы`, плюс корзина и папка Загрузки.

## 1–2. Установка одной командой

Открой **обычный** PowerShell, не от администратора, и вставь целиком содержимое
[`bootstrap.ps1`](bootstrap.ps1). Winget не нужен. Скрипт сам:

1. Скачает и тихо поставит **Python 3.12** в профиль пользователя. Твой старый Python из PyCharm не трогает.
2. Скачает **ffmpeg** в `C:\AI\ffmpeg` и пропишет его в PATH пользователя.
3. Скачает и поставит **OBS Studio**. Тут выскочит окно прав администратора, жми **Да**.
4. Склонирует эту репу в `C:\AI\claude`. Если репа приватная, Git попросит залогиниться в GitHub.
5. Запустит [`install.ps1`](install.ps1): клонирует Deep-Live-Cam, создаст venv, поставит зависимости,
   torch под CUDA 12.8, onnxruntime-gpu, CUDA/cuDNN pip-пакетами, скачает модели
   и проверит, что всё реально работает на видеокарте.

CUDA Toolkit ставить не надо. Нужны только свежий драйвер NVIDIA и Git.
Займёт 15–25 минут. В конце должна быть строка **OK: swap будет на видеокарте**.

Всё ляжет в `C:\AI\claude\deep-live-cam\Deep-Live-Cam`. Запуск потом всегда через `start.bat` в этой папке.

Повторный запуск безопасен: уже установленное пропускается.

## 3. Настрой подмену

1. Запусти `start.bat`. Откроется окно.
2. **Select a face** → фото того, кем хочешь быть. Анфас, ровный свет, без очков, рот закрыт.
3. Включи галочки:
   - **Face Enhancer**: лицо резче. Если fps проседает ниже 20, выключи.
   - **Mouth Mask**: твой рот остаётся родным, речь выглядит естественно.
   - **Keep fps** можно не трогать.
4. Нажми **Live**, выбери вебку. Первый запуск думает 10–30 секунд, дальше летает.
5. Появится окно превью с подменённым лицом. Не закрывай его, OBS будет его захватывать.

## 4. OBS как виртуальная камера

1. Открой OBS. В блоке **Источники** нажми `+` → **Захват окна** → выбери окно превью Deep-Live-Cam.
2. Правый клик по источнику → **Фильтры** → `+` → **Обрезка/выравнивание**, обрежь рамки окна.
3. Растяни картинку на весь холст: правый клик → **Трансформация** → **Подогнать под экран**.
4. Справа внизу нажми **Запустить виртуальную камеру**.

Сцену можно сохранить, в следующий раз просто жмёшь одну кнопку.

## 5. Выбери камеру в созвоне

- **Discord**: Настройки → Голос и видео → Камера → `OBS Virtual Camera`.
- **Zoom**: Настройки → Видео → Камера → `OBS Virtual Camera`.
- **Telegram Desktop**: при звонке иконка камеры → выбор устройства → `OBS Virtual Camera`.

Порядок запуска каждый раз: `start.bat` → Live → OBS → Виртуальная камера → созвон.

## 6. Советы по качеству

- **Свет решает всё.** Лампа спереди, никаких окон за спиной. Иначе лицо мерцает.
- **Похожее фото.** Чем ближе форма лица, причёска и ракурс источника к твоим, тем меньше швов.
  Модель меняет только лицо. Волосы, уши, шея остаются твои.
- **Не крути головой резко.** На профиле модель теряет лицо на пару кадров.
- **Разрешение вебки 720p.** 1080p на 4060 Laptop уже тянет fps вниз.
- **Ноут в розетке и в режиме производительности.** На батарее видеокарта режет частоты.

## 7. Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Проверка в конце `install.ps1` пишет «сессия на CPU» | Старый драйвер NVIDIA. Обнови, перезагрузись, снова `install.ps1`. Если не помогло, план Б: поставь CUDA Toolkit 12.8 с сайта NVIDIA. |
| `cudnn64_9.dll not found` при запуске | В venv не встал `nvidia-cudnn-cu12`. Активируй venv и выполни `pip install nvidia-cudnn-cu12`. |
| Скрипт не нашёл Python 3.11–3.13 | Поставь Python 3.12 с python.org руками и запусти `bootstrap.ps1` снова. |
| Кракозябры или ошибки парсинга в `install.ps1` | Файл должен быть в UTF-8 с BOM. Скачивай через `git clone`, а не копипастой в Блокнот. |
| Чёрное окно превью | Вебку занял другой процесс. Закрой Discord/Zoom, запусти Deep-Live-Cam, потом открывай созвон. |
| 3–5 fps | Запустилось на CPU. Смотри первую строку таблицы. |
| Лицо плывёт по краям | Выключи Face Enhancer, добавь света, поменяй фото источника. |
| `python` не найден | Переустанови Python с галочкой Add to PATH, перезапусти PowerShell. |

## 8. Про Абаддона

Face swap натягивает только лицо, капюшон и доспех не появятся. Для Абаддона целиком нужен
VTuber-вариант: вытащить 3D-модель из Dota 2 через Source 2 Viewer, перегнать в VRM через Blender,
и крутить в VSeeFace с трекингом лица. Это отдельный гайд, если понадобится.

## Правила приличия

Своё лицо, лицо друга с его согласия, фанарт или сгенерированное лицо: окей.
Реальный чужой человек без согласия: во многих странах уголовка, не надо.
